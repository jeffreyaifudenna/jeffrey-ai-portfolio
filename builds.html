This site

Oct 2026LiveClaude Code · Plain HTML · Vercel

Four HTML pages, one shared stylesheet, no framework and no build step. Written in Claude Code, designed by hand. Twelve color themes and a holiday accent that reads the Hebrew and Chinese calendars, and a news section that fills itself from a JSON file the morning task writes. A plain-text map of the site sits alongside the pages so AI agents can read it as easily as people do.

Prompts

Daily AI News, the plan it runs on

Find 3 to 5 of the most important AI stories from the past day: new tools to build with, big industry news, policy and safety, and research explained simply. Open every link to make sure it works. Write each summary in your own words, 2 to 3 sentences, and add one sentence on why it matters. Label anything reported by only one outlet as Reported, and anything from rumor as Unconfirmed. Then publish the digest to the News page.

The Infinite Buddha, the image prompt

A serene terracotta Buddha meditating in a small wooden garden shrine, ferns and vines around it, soft morning light, photographic, square. Change the setting, season and material every day. Never repeat yesterday's scene. Sent to Gemini each morning by a Python script on GitHub Actions. The script picks the day's setting from a list and publishes the result.

How the work gets done

  1. Start with the thing, not the tool. Each project began as something I wanted to exist: a daily piece of art, a page of real numbers about my city, a story. The AI is picked after.
  2. Let it run on its own where it can. Two of the builds publish themselves every morning on a schedule. If a project can be automated, it is, so it keeps living after I stop touching it.
  3. Check what it says. The news task opens every link before it publishes and labels anything that isn't confirmed. Every number on the Fremont site shows its source and date.
  4. Keep the stack small. Plain HTML, JSON data files, one script where needed. No build step unless the project really needs one.
  5. Show the prompt. Where a prompt does the work, it's published next to the result, so you can see exactly what the model was asked.
